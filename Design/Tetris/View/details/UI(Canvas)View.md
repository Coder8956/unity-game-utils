# UI(Canvas) Tetris View Design

## 代码规范

- 代码目录`Assets\Demo\Scripts\TetrisGame\TetrisView\UI`
- UI使用Unity Canvas UI

## 显示要求

- 用UI元素(Canvas子物体)实现游戏过程的显示(例:正方形Image)

## 游戏元素

- 游戏元素都是单位元素(例:正方形)
- 使用一个变量(float类型)配置元素的边长(长和宽)
- 使用Image表现具体元素
